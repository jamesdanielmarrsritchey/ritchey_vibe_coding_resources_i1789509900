# Mandate: Compliance Report

I mandate that every time a new release is made, a new plain-text file named "Compliance Report.txt" be added to the main folder of project. If there is a previous compliance report file present, it can be overwritten. This file must contain the results of an examination of each code file in the project, stating any deviations from specifications, mandates, and preferences. It must state the reasons for non-compliance. It must provide an overall compliance score. An example is provided below.

EXAMPLE COMPLIANCE REPORT:
"
# Compliance Report

Date: Y2026M9D17 (September 17, 2026)
Compliance Score: 99%
Non-Compliant Files:
- "/Source/includes/webpages_template_v1.php": 
 - This file is not compliant with "Preference - OOP", because it relies on PHP that needs OOP. 
 - This file is not compliant with "Preference - Comments", because the developer specifically requested this file have no comments. Comments can be added in future releases if the developer wishes.
"
