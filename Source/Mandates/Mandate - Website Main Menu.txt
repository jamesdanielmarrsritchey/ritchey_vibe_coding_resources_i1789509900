# Mandate: Website Main Menu

I mandate that on websites with a main navigation menu, there should be a button with a humburger menu icon, that links to a page called Navigation, rather than having normal pop-out menu. The menu button should just display the hamburger menu icon on portrait screens, but on landscape screens it should have "Navigation" as text beside it. When on the Navigation page, this page should not contain the normal headers/footers of the website. It should just contain the menu content, and a single header, with a back arrow, and the text "Return" if the previous URL is known. If the previous URL is not known, the header should be empty.

The page should divide menu entries into types: pages, meta pages, tools, miscellaneous. The pages section should be the default. It generally contains links to pages like the homepage, Browse, and Search. Meta is only for pages about the site such as the about page, legal page, supported systems page, statistic page, version page, link to robots.txt, link to humans.txt, or link the sitemap.xml or sitemap_index.xml. The tools section is for special widget pages that host useful webtools. The miscellaneous section is anything that doesn't fit into a category such as a link to a Hello World.txt file.
